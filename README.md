## Overview

ASCOMP Image Former provides a practical Windows-based workspace for converting images and applying changes to groups of files. Instead of editing images one by one, users can handle common jobs such as resizing, cropping, and format conversion in a more efficient workflow.

The utility is suited to both everyday image management and repeatable processing tasks involving large collections. It supports more than 50 image formats, can retain metadata, and includes optimization features for preparing files for storage, distribution, or publication.

- Resize or crop images while using preview support

## Using the Application

To perform a conversion, select the source image files, choose the desired output format, and specify where the results should be stored. Optional resizing, cropping, and optimization settings can be configured before the job begins.

A standard workflow looks like this:

1. Select individual files or add a complete folder.
2. Pick the destination format.
3. Configure any resize, crop, or compression options.
4. Enable metadata retention if EXIF or IPTC data should remain available.
5. Begin the job, then inspect the generated files.

CLI mode is available when conversion tasks need to be repeated from scripts or scheduled processes.
